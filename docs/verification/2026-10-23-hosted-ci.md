Hosted CI 证明当前提交在公开 runner 上的三 OS 自动化矩阵、SQLite 独立包闭环和真实 PostgreSQL 16 测试通过。它不证明 Claude Code 真实历史格式兼容，也不证明用户机器上的 Claude Code 客户端发现与加载。真实 Codex 历史样本、指定模型端点和人工来源门禁由独立本地记录覆盖。npm 包仍未发布。
